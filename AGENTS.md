# Penunjuk Aturan Workspace

Repo ini berisi dua proyek konten. **Baca aturan proyek yang sedang dikerjakan sepenuhnya sebelum mengerjakan tugas apa pun**, termasuk bagian "Alur Kerja Episode Baru" di masing-masing file.

| Proyek | Folder | Aturan lengkap |
|---|---|---|
| Cerita Cerdik (Ki Udin, komedi claymation) | `cerita-cerdik/` | `.agents/AGENTS.md` |
| Jangan Tonton Sendirian (creepypasta rumah tangga, semi-realistis gelap) | `jangan-tonton-sendirian/` | `jangan-tonton-sendirian/.agents/AGENTS.md` |

Jika permintaan tidak menyebut proyek (mis. "eps selanjutnya", "kasih ide"), ikuti proyek dari file yang sedang dibuka atau disebut; bila tetap tidak jelas, tanyakan dulu.

File ini hanya penunjuk untuk agent yang membaca `AGENTS.md` dari root repo (mis. Codex). Jangan menambahkan aturan di sini.

Skill ada di `.agents/skills/`:
- Cerita Cerdik: `idea-hunter`, `flsr-winning-content`, `neuromarketing-director`, `ths-content-evaluator`
- Jangan Tonton Sendirian: `jts-idea-hunter`
- Keduanya: `meta-analytics-ingest` (pakai `--tracker` untuk memilih tracker proyek), `comment-humanizer`
