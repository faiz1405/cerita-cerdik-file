# [theme]
Kisah kecerdikan rakyat jelata Nusantara claymation POV KI UDIN — Detektif Desa (Test Ombak 3). Desa diteror hantu bola api (Banaspati) setiap tengah malam, membuat warga ketakutan dan mengunci diri di rumah. Ki Udin menginvestigasi dan menemukan bola api itu selalu mengarah ke kandang sapi. Terbongkar bahwa itu hanyalah trik maling sapi yang menyalurkan gas rawa/fosfor lewat pipa bambu rahasia agar warga takut keluar rumah. Maling tertangkap basah.
